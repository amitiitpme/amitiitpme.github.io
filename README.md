# Amit Singh — Professional Portfolio

A responsive, premium-dark personal portfolio built with HTML, CSS and vanilla JavaScript. Designed for GitHub Pages.

## Included
- `index.html` — single-page portfolio
- `style.css` — responsive visual system and animations
- `script.js` — mobile navigation, reveal effects and scroll progress
- `projects/` — four detailed project case-study pages
- `assets/documents/Amit-Singh-Resume.pdf` — downloadable resume
- `assets/images/` — add your professional portrait and approved project images here

## Before publishing
1. Add your professional photo as `assets/images/profile.jpg`.
2. In `index.html`, replace the `.portrait-placeholder` block with:
   `<img class="profile-photo" src="assets/images/profile.jpg" alt="Amit Singh">`
3. Add the following CSS to `style.css`:
   `.profile-photo{width:100%;height:100%;object-fit:cover;border-radius:50%}`
4. Review every achievement, date, service description and public disclosure for accuracy.
5. Add only photographs and documents you are authorized to publish.

## Publish with GitHub Pages
1. Create a GitHub account at https://github.com/ if you do not already have one.
2. Create a new **public** repository named exactly `YOUR-USERNAME.github.io`.
3. Upload the contents of this folder (not the outer folder itself) to the repository root.
4. In repository Settings → Pages, select **Deploy from a branch**, choose `main` and `/ (root)`, then Save.
5. Wait for the Pages deployment to finish. Your site will be at `https://YOUR-USERNAME.github.io/`.

## Local preview
Open `index.html` in a browser. For best results, use a simple local static server or VS Code Live Server.

## Accuracy and confidentiality
Content is drafted from the resume supplied for this portfolio. Case-study pages are summaries, not controlled engineering records. Confirm that all dates, metrics, customer references, and claims are suitable for public disclosure before publishing. Do not upload employer/customer confidential information, drawings, specifications, audit records, or controlled documents.
